# Imported Slides

You can split your slides.md into multiple files and organize them as you want using the `src` attribute.

#### `slides.md`

```markdown
# Page 1

Page 2 from main entry.

---

## src: ./subpage.md
```

<br>

#### `subpage.md`

```markdown
# Page 2

Page 2 from another file.
```

[Learn more](https://sli.dev/guide/syntax.html#importing-slides)

# P0 Trust, Security & Data Governance  
> **“Non-negotiable” — universal high priority**  
- Granular permissions & tagging  
- Source citation + fact-check trail  
- No PII/IP leakage, closed-system option  
- Audit / approval workflow  
- Public vs. internal versions, dynamic disclaimers

---

# P1 Persona Core & Insight Engine  
- Guided builder w/ **EBP dimensions**  
- Panels & cohort grouping  
- Map to buying triggers  
- Deep reasoning & signal extraction  
- Unified search across open data

---

# P2 “Living” & Interactive Personas  
- **Evolving personas** (culture shifts, data refresh)  
- Natural-language chat; multi-persona sims  
- Persona-as-usability-tester for prototypes  
- Context memory, tone sliders

---

# P1-P2 Output & Automation  
- Adjustable length snippets, bios, case studies  
- Tailored deck generator (1-pager → full kit)  
- Multi-format export (PDF, PPT, email)  
- Save user prefs & variants
